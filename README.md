# Random Forest for Handwritten Digit Recognition

This repository reproduces the central empirical claim of Breiman's
historical random forest work on a small, fully reproducible computer-vision
task. The experiment compares three models on the 1,797-image handwritten
digit dataset bundled with scikit-learn:

- a single CART decision tree (`baseline`);
- bagging with all pixel features (`ablation`);
- a random forest with bootstrap sampling and random pixel subspaces
  (`proposed`).

The project includes source code, serialized model weights, machine-readable
results, figures, and a Chinese manuscript with an English abstract. Every
number reported in the paper is generated by `src/run_experiment.py`.

## Reported results

Five model seeds were evaluated on the same fixed stratified test split of
360 images. The means and standard deviations are:

| Method | Accuracy | Macro F1 |
|---|---:|---:|
| Single decision tree | 86.39% ± 0.44% | 86.38% ± 0.36% |
| Full-feature bagging | 95.67% ± 0.25% | 95.64% ± 0.24% |
| Random forest | 98.28% ± 0.53% | 98.26% ± 0.55% |

The random forest also degrades much less under Gaussian pixel noise and
central occlusion. See `results/metrics.json` and the manuscript for the full
analysis, including the less favorable probability-calibration result.

## Environment

The reported run used:

- Python 3.12
- scikit-learn 1.5.2
- NumPy 2.1.3
- SciPy 1.14.1
- Matplotlib 3.9.2
- CPU execution

Install dependencies with:

```powershell
python -m pip install -r requirements.txt
python -m pip install -r requirements-doc.txt
```

## Reproduce

Run from this directory:

```powershell
powershell -ExecutionPolicy Bypass -File run_all.ps1 -Python python
```

The script is deterministic by default, writes the three `.joblib`
checkpoints to `checkpoints/`, and writes all raw metrics to `results/`.
Figures are written to `figures/`. On Windows with Microsoft Word installed,
export the final PDF with:

```powershell
powershell -ExecutionPolicy Bypass -File src/export_pdf.ps1
python src/audit_pdf.py
```

To regenerate only figures from completed results:

```powershell
python src/make_figures.py
```

Build the manuscript and verify saved checkpoints:

```powershell
python src/evaluate_checkpoints.py
python src/build_paper.py
python src/make_manifest.py
```

The final deliverables are:

- `paper/Random_Forest_Digit_Reproduction_Paper.docx`
- `paper/Random_Forest_Digit_Reproduction_Paper.pdf`
- `results/metrics.json`
- `checkpoints/*.joblib`

## Data

`sklearn.datasets.load_digits` is bundled with scikit-learn, so no network
download is required. It contains 1,797 grayscale images of handwritten
digits, each represented as an 8 x 8 matrix with values in `[0, 16]`.
The classes range from 0 to 9 with near-balanced frequencies.

## Checkpoints

- `checkpoints/baseline_tree.joblib`
- `checkpoints/bagging_all_features.joblib`
- `checkpoints/proposed_random_forest.joblib`

Each checkpoint stores the fitted estimator, split seed, model seed, input
shape, and evaluation metadata. Load one with:

```python
import joblib
artifact = joblib.load("checkpoints/proposed_random_forest.joblib")
model = artifact["model"]
pred = model.predict(X_test)
```

## Integrity

The main split and all model hyperparameters are fixed before test
evaluation. The test set is not used for hyperparameter selection. Five
model seeds are evaluated on the same held-out set; the paper reports mean
and standard deviation, while the saved checkpoint uses the declared
`checkpoint_seed`.
